# Changelog

Все заметные изменения этого проекта документируются в этом файле.

## 0.6.0 — 2026-08-21

### Добавлено

- Ручная проверка обновлений через **Справка → Проверить обновления…**: приложение в фоне сверяет SemVer-версию с последним стабильным GitHub Release и при необходимости открывает страницу релиза в браузере.
- Отдельная пиктограмма команды проверки обновлений в меню «Справка».
- При ошибке проверки обновлений диалог предлагает открыть текущий файл журнала.
- Команда очистки списка недавних баз в разделе «Недавние» и меню «Вид»; удаляется только история запусков.
- Оценка размера кэша перед очисткой и понятное отображение освобождённого места.
- Копирование значения или всей строки параметра из таблицы сведений о выбранной базе.
- Поиск по всем реквизитам базы, включая путь, сервер и строку подключения.
- Локальные теги баз, поиск по ним и фильтр «Все базы / Избранные / Тег».
- Настройка цвета фона и текста для каждого тега с отображением в карточке базы.
- Сортировка всего списка и отдельных папок: исходный порядок, имя или последний запуск.
- Паспорт базы в основной карточке: локальные сведения о файловой базе и `Srvr`/`Ref` для клиент-серверной без доступа к SQL Server.
- Единое локальное хранилище метаданных каталога `catalog-state.json`: избранное, история, даты запусков, теги, их стили и настройки сортировки.
- Виртуальный раздел «Избранное» в дереве располагается перед «Недавними» и обычным каталогом.
- Наглядное перетаскивание в дереве: запись следует за курсором, подсвечивается место вставки, доступен перенос в группу, корень списка и между соседними записями.
- Расширенный простой режим: компактное окно сохраняет поиск, список баз, строку подключения, запуск и контекстные команды каталога.
- Демонстрационный `ibases.v8i` для ручной проверки и создания скриншотов без реальных подключений и персональных данных.

### Исправлено

- Ручная перестановка и перетаскивание не изменяют невидимый исходный порядок, когда для папки включена сортировка по имени или запуску.
- Теги с квадратными скобками и кавычками корректно сохраняются и загружаются из `catalog-state.json`.
- При обработке legacy веб-подключений сохраняются неизвестные фрагменты адреса.
- После закрытия внутренних окон редактирования главное окно возвращает активность без принудительного изменения переднего плана.
- Распознаются форматированные подключения `File=…` при поиске файловых баз; открытие папки и очистка кэша используют корректные пути.
- Выбор файловой базы на UNC-пути или подключённом сетевом диске не блокирует окно: карточка не запрашивает размер и дату изменения сетевого `1Cv8.1CD`.
- Карточка базы, меню, диалоги и выбор записи корректно обновляются после редактирования, смены сортировки, перезагрузки списка и работы с тегами.

### Инфраструктура

- Обновлены документация, тесты, релизный процесс и материалы для публичного репозитория.

## 0.5.1 — 2026-08-14

### Исправлено

- При редактировании веб-базы с прямым URL в `Connect` исходный URL больше не добавляется повторно после `WS="…"`; сохраняется корректная строка подключения.

## 0.5.0 — 2026-08-14

### Добавлено

- Нативное x64 приложение Windows на C++20, CMake и Win32 Common Controls.
- Автозагрузка стандартного `ibases.v8i`, выбор альтернативного файла и работа с UTF-8.
- Сохранение неизвестных полей, атомарная запись, резервные копии и защита от внешнего изменения файла.
- Дерево групп и баз, поиск, добавление файловой базы/группы, редактирование, безопасное удаление записи, создание ярлыка.
- Поиск установленных платформ 1С, выбор x64 перед x86, построитель команд запусков, запуск Enterprise/Designer.
- Локальные настройки, portable mode, история, избранное, ротация логов и маскирование секретов.
- Очистка ограниченных каталогов кэша, обнаружение активного процесса 1С и API фонового поиска файловых баз.
- Unit-тесты, CTest, ограничение размера EXE, GitHub Actions build/release workflows и документация.
- Единый SemVer-номер продукта, отображение версии в окне «О программе» и свойствах Windows-файла.
- Автоматическое создание version tag и GitHub Release после принятия pull request в `main`.
- Исправлено отображение стандартной иерархии `ibases.v8i` с абсолютными путями `Folder=/…`; строка состояния показывает число найденных баз.
- Поиск по базам не зависит от регистра кириллицы и подсвечивает каждый совпавший фрагмент имени зелёным.
- Добавлено контекстное меню дерева с запуском, избранным, редактированием, очисткой кэша, ярлыком, удалением, добавлением в выбранную группу и перемещением вверх/вниз.
- Добавлены оригинальный значок IBStart, пиктограммы кнопок и элементов дерева, а сведения о выбранной базе оформлены как цветная двухколоночная карточка.
- Включён Common Controls v6: значки дерева теперь используют прозрачность без чёрного фона, а пиктограммы отображаются на кнопках; контекстное меню получило цветные значки для всех действий.
- Подписи кнопок теперь рассчитывают ширину по фактическому тексту, значку и DPI; дерево различает файловые и серверные базы отдельными яркими пиктограммами.
- Кнопки, поиск, дерево и таблица свойств используют масштабируемый Segoe UI с ClearType вместо системного растрового шрифта.
- Сочетания в контекстном меню вынесены в отдельную приглушённую колонку; добавлены работающие клавиатурные ускорители для всех его команд и подсказки комбинаций у основных кнопок.
- Единый редактор баз заменил ввод сырой строки `Connect`: доступны имя базы, файловое/веб/серверное подключение и параметры запуска; пользовательские диалоги центрируются относительно IBStart и используют тот же Segoe UI с ClearType.
- В параметрах запуска добавлена разрядность `AppArch`: только 32/64-bit и приоритет 32/64-bit; при запуске IBStart учитывает `AppArch`, а `/AppArch` из `AdditionalParameters` имеет более высокий приоритет.
- Добавлено окно «Дополнительные настройки базы» со справкой по служебным полям `ibases.v8i`, поддержкой `DefaultVersion` и `OrderInTree`; кнопки главного окна получили атомарную адаптивную раскладку без следов и наложений при изменении размера.
