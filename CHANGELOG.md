# Changelog

Все заметные изменения этого проекта документируются в этом файле.

## 0.8.0

### Проверка перед выпуском

- В конструкторе параметров кнопки добавления команды, изменения параметра и удаления выровнены в один ряд; отступ от списка сохраняется при изменении размера окна.
- Исправлен запуск с явно пустым паролем `/P ""`, сформированным конструктором: пустое значение отличается от отсутствующего аргумента; пропуск значения по-прежнему блокируется.
- Импорт и экспорт отклоняют профили с остатками незавершённой операции от любого процесса, включая предыдущий запуск, сохраняя файлы восстановления. При импорте без учётных записей текущие учётные записи читаются под общей блокировкой записи профиля.
- Windows-проверки сборки и выпуска останавливаются при ошибке каждого генератора справочных данных. Изменение значка сайта отслеживается зависимостями сборки ресурсов.
- План развития разделяет текущие возможности, будущие этапы и их статусы; для чтения конфигурации и версии из базы подготовлен отдельный бриф. Подключение через COM и проверка актуальных релизов конфигураций в 0.8.0 отсутствуют.

### Добавлено

- Настройка «Проверять обновления при запуске программы», включённая по умолчанию. Фоновая проверка сообщает о новой версии пунктом «Доступно обновление …» после «Справка» (после «Режим» в простом режиме), без всплывающих окон. Снятая галочка отключает запрос при запуске; ручная проверка сохраняется.
- Справочник конфигураций с полями «Имя», «Наименование» и «Краткое наименование», постоянными идентификаторами и начальным набором БП, ЗУП, УТ11, ERP 2, УНФ 3.0 и Розницы 3.0. Справочник доступен через меню «Инструменты» и редактор базы.
- Выбор конфигурации и ручная версия каждой базы, независимые от версии платформы и конструктора запуска. Поиск по новым сведениям, метки в дереве с отдельной настройкой показа, полные значения в карточке и подсказке. Связи разных файлов списков изолированы; профиль переносит справочник вместе с привязками.

- Общий конструктор параметров запуска: команды с описаниями, поиск, категории, редакторы значений и файлов, итоговая строка. Кнопка «Конструктор…» доступна в разовом запуске и дополнительных настройках базы; результат возвращается в исходное поле, отмена не меняет его.
- Команда **Инструменты → Конструктор параметров запуска…** открывает ту же форму без выбранной базы для самостоятельной проверки и копирования строки, без сохранения параметров и запуска 1С.
- Каталог совместимости по 24 справочникам ИТС: 8.3.6–8.3.27, стабильная 8.5.1 и тестовая 8.5.4. Команды и варианты значений учитывают выбранную версию; неизвестные версии не наследуют соседний профиль. Сложные, пакетные, web/mobile и служебные операции показаны как справочные.
- Отдельная матрица версий и инструмент её обновления из документации без включения страниц ИТС в исходный код или поставку.
- Встроенные пояснения всех 166 пунктов каталога: назначение, смысл значений и вложенных опций. Тексты написаны своими словами по официальной документации, входят в EXE и не требуют внешних файлов; для перечислений учитывается выбранная версия. Для несовместимых команд отображаются первая документированная версия и диапазоны наличия.

### Исправлено

- Команда «Сайт проекта» и ссылка в окне «О программе» открывают сайт приложения `https://ant-m13.github.io/ibstart/`.
- Сохранены номера существующих значков меню при добавлении новых. Устранена подмена значка «Теги» значком учётных записей в локальной неполной сборке; добавлена проверка настоящего контекстного меню и уточнена обязательная полная пересборка перед выпуском.
- Значения в кавычках, похожие на `/AppArch` или `/AppArch=x86`, больше не принимаются за выбор разрядности: имя пользователя, пароль или имя файла не блокируют запуск и не меняют подбор платформы.

- Разные значки для команд главного меню: пользователь с ключом у «Учётные записи…», карточки справочника у «Конфигурации…» и параметры со стрелкой запуска у «Конструктор параметров запуска…» вместо одинакового карандаша.
- Реквизиты в справочнике конфигураций разделены на колонки «Имя», «Наименование» и «Краткое наименование» с заголовками, сеткой и изменяемой шириной. «Добавить…» открывает отдельное небольшое окно с пустыми полями, «Изменить…» — с текущими данными. Сохранение и отмена выполняются в этом окне; в справочнике остаются таблица, поиск и действия над записями.
- Команды без аргументов распознаются по синтаксису выбранной версии: исправлены `/ClearCache`, `/UnregServer`, `/AgentMode` и другие команды, ошибочно остававшиеся справочными. Добавленная команда без аргументов предлагает удаление. Кнопка «Добавить команду в строку» вставляет имя команды отдельно от её опций; обязательные значения можно заполнить после вставки, проверка перед применением сохраняется. Для исторической `/DisplayAllFunctions` сохранены ограничения версий и добавлена подсказка о `/TechnicalSpecialistMode`.
- Основной аргумент команды теперь доступен и без вложенных опций: исправлены `/EmailAuth <email>`, `/URL <адрес>`, `/RunShortcut <имя файла>`, `/DumpIB <имя файла>` и другие команды с тем же пропуском редактора. Поля, обязательность и ограничения выбираются по версии; сообщение об отсутствии отдельных полей больше не появляется при доступном редакторе. Проверены 26 команд в 373 сочетаниях с профилями.
- Проведена смысловая сверка всех 166 пунктов каталога и 297 пар «команда + вложенная опция» по 24 версиям документации. Уточнены выбор сертификатов, имена источников сравнения, политики паролей и мобильная справка; добавлены проверки явно описанных зависимостей и конфликтов, кавычки при структурированном вводе и поле имён `/DisableExtensions`. Для `/ConfigurationRepositoryAddUser -Rights` оставлен выбор одного из четырёх значений с заменой прежнего. Добавлена проверка покрытия справки по документации.
- Исправлены типы значений конструктора по 24 справочникам: `/debug` предлагает одно поле режима `-tcp`/`-http` и отдельный необязательный `-attach`, проверяет несовместимость TCP с автоматическим подключением. Конечные перечни вложенных значений выбираются из списка выбранной версии; имена конфигураций, пути и сложные списки сохраняют свободный ввод. Добавлены редакторы знака режима `/AppAutoCheckVersion` и `/AppAutoInstallLastVersion`.
- В самостоятельном конструкторе доступны `/F`, `/S`, `/WS`, `/IBName` и `/IBConnectionString`; в дополнительных параметрах базы ограничение объясняется и проверяется при применении. Добавленный флаг без значения предлагает удаление, команда со значением — изменение и отдельное удаление. Кнопки обновляются при ручной правке строки; неоднозначные фрагменты сохраняются для ручного редактирования.
- Прокрутка справки к выбранному вложенному параметру учитывает внутренние переводы строк форматированного поля. Заголовок вроде `• -NoCheck` остаётся видимым вместе с описанием, включая заголовки с переносом строк.
- В описании конструктора команды выделены жирным, а вложенные параметры и обозначения аргументов — цветом. Поле поддерживает выделение и копирование текста; при высокой контрастности используются системные цвета и жирное выделение. Оформление сохраняется при смене версии, масштаба и системных цветов.
- Пояснения команд и вложенных опций сверены со всеми 24 версиями документации ИТС: уточнены значения по умолчанию, единицы измерения, ограничения, приоритеты и различия профилей. Контекстные описания встроены в EXE; поиск учитывает полный текст справки, включая поля строки соединения и веб-клиента. Добавлены справочные `/AddToList`, историческая `/AddInList` и `/UseTemplate`. Исправлены ранние версии появления двух команд, необязательность имён файлов при наличии документированного значения по умолчанию и выбор режима локального распознавания речи в 8.3.24–8.3.26.
- Основные аргументы конструктора названы по синтаксису выбранной версии, например «каталог загрузки». Пояснение `/LoadConfigFromFiles` дополнено ограничениями загрузки и различием полной и частичной загрузки; при документированном `-Format` проверяется его наличие для `-files`/`-listFile`. Расхождение в справочнике тестовой 8.5.4 показано отдельно.
- Вложенные параметры конструктора следуют порядку справочника выбранной версии. Обязательные параметры отмечены `*`, проверяются пропуски, зависимые группы и альтернативы; у `/Proxy` учитываются обязательные `-PSrv`, `-PPort` и зависимость пароля от пользователя. Значения и неизвестные фрагменты сохраняются при перестановке опций.
- Пакетные команды Конфигуратора проверяются на соответствие режиму запуска, включая команды с вложенными параметрами. Самостоятельный конструктор позволяет составлять их без выбранной базы.
- Описания сложных команд показывают версионный синтаксис и каждый вложенный параметр отдельным блоком. Добавлен выбор вложенного параметра с вводом значения, изменением и удалением без перезаписи соседних опций. `/ConfigurationRepositoryCreate` раскрывает все семь параметров и правила поддержки; `/SetPredefinedDataUpdate` предлагает три режима с объяснением поведения главного и периферийного узлов.
- Адрес, пользователь и пароль хранилища (`/ConfigurationRepositoryF`, `/ConfigurationRepositoryN`, `/ConfigurationRepositoryP`) редактируются через поля конструктора для режима Конфигуратора. Пометка об отсутствии отдельных полей больше не называет работающую команду «справочной»; пароль хранилища скрывается в журнале и предпросмотре запуска.
- Ошибочные сохранённые параметры больше не препятствуют открытию окна разового запуска для исправления. Проверки остаются обязательными перед запуском и используют фактически выбранную платформу.
- Изменение отдельного параметра сохраняет окружающий текст, неизвестные ключи и порядок аргументов. `/AppArch` из разового ввода учитывается при подборе платформы.
- Версию справочника можно вводить посимвольно без замены префикса первым пунктом списка. Если версия не указана, конструктор выбирает старшую установленную платформу, а при отсутствии установок — стабильный профиль 8.5.1. Повторяющийся служебный текст об успешной сверке убран из описаний.

## 0.7.7

### Добавлено

- Добавлен безопасный фоновый расчёт размеров локального кэша для выбранной базы, всех баз текущего списка и базы вместе с вложенными папками. Расчёт последовательно обрабатывает базы, показывает прогресс и сохраняет завершённые результаты даже при ошибке другой базы.
- Размеры кэша сохраняются в `catalog-state.json` вместе с датой измерения и признаком полноты. Полный нулевой результат отображается как `0 Б`, а неполный — с приблизительным знаком `≈` и предупреждением в карточке базы.
- В дерево добавлен нейтральный чип `Кэш …`, в карточку базы — блок «Размеры» с размером, временем измерения и состоянием. Настройка отображения доступна в форме **Настройки → Параметры приложения… → Интерфейс → Основные** и быстрым пунктом **Вид → Показывать размеры кэша в списке баз**.
- После очистки кэша выполняется повторное безопасное сканирование фактического остатка; старое измерение инвалидируется после подтверждения очистки, а ложный `0 Б` при отмене или ошибке повторного сканирования не сохраняется.
- Добавлена отдельная пиктограмма `cache_size.ico` для команд расчёта размера кэша. `ibases.v8i` по-прежнему не изменяется этой функциональностью.

### Безопасность

- Расчёт и очистка используют только прежние разрешённые корни кэша, не следуют пути из `Connect`, не заходят в каталог файловой базы и не пересекают `licenses`, `license`, `lic` или небезопасные reparse point. Недоступные элементы дают частичный результат вместо незаметного точного значения.
- Измерение инвалидируется при изменении подключения, стабильного идентификатора или удалении базы; переименование с сохранением явного `ID` сохраняет метрику.

### Тесты и документация

- Добавлены проверки сканирования, отмены, persistence метрик, фоновой очереди результатов и правил миграции/инвалидации.
- Обновлены руководство пользователя, справочник конфигурации и описание архитектуры.

## 0.7.6

### Добавлено

- В контекстное меню базы добавлена команда «Запуск с параметрами…» без подменю. Она открывает отдельное окно для разового выбора режима (Предприятие/Конфигуратор), установленной платформы, типа клиента, разрядности, пользователя 1С, пароля и дополнительных параметров.
- В окне специального запуска добавлен безопасный предварительный просмотр сформированной команды, а пароль и другие секреты маскируются.
- Кнопка «Копировать команду» копирует полную сформированную команду без маскирования; предварительный просмотр при этом остается обезличенным.
- Для новой команды добавлена собственная пиктограмма в стиле owner-draw меню.
- Добавлен справочник «Настройки → Учётные записи…» с открытым хранением логинов и паролей в `settings.json`, областью применения по базам и группам и выбором подходящей записи при запуске с параметрами. Групповые правила включают вложенные и новые базы; ссылки к другим спискам и отсутствующим элементам сохраняются для редактирования.
- Добавлено компактное окно «Настройки → Параметры приложения…» с вкладками «Интерфейс», «Запуск», «Данные» и «Профиль»: в нём собраны основные параметры интерфейса, дополнительные пути поиска платформ 1С, редакторы учётных записей и тегов, лимит недавно открытых списков и операции очистки истории.
- Для команд «Параметры приложения…» и «Учётные записи…» в меню «Настройки» добавлены отдельные пиктограммы; настройки больше не используют иконку приложения.
- Размер пиктограммы настроек в меню скорректирован, чтобы она полностью помещалась в выделенной области.
- Для недавно открытых списков добавлено удаление отдельного пути без удаления самого файла, а для виртуальной ветки «Недавние» — удаление отдельной базы только из истории запусков.
- Добавлены настройки запуска: открытие последнего списка и восстановление выделения, клиент, разрядность и версия платформы по умолчанию.
- Добавлены отдельные переключатели подтверждения потенциально разрушающих операций; запуск с секретами не требует отдельного предупреждения.
- Добавлены настройки внешнего вида: плотность строк дерева, видимость карточки базы и строки состояния.
- Добавлено управление историей запусков: её можно отключить и ограничить пятью, десятью или двадцатью базами без удаления независимых времён последнего запуска.
- Для дополнительных путей поиска платформы 1С добавлены команды изменения порядка, а в секцию профиля — кнопка открытия папки собственных данных IBStart.
- Добавлены экспорт и импорт собственного профиля IBStart в виде папки с `settings.json` и `catalog-state.json`; экспорт секретов и их импорт требуют отдельного подтверждения.

### Безопасность

- Параметры специального запуска не изменяют `ibases.v8i`. Учётные записи сохраняются только явным действием в справочнике; разовые изменения полей запуска их не перезаписывают. Пароли отображаются открыто в полях и справочнике; предварительный просмотр команды и журналы сохраняют маскирование секретов. Наличие секрета само по себе не блокирует запуск и не вызывает отдельного подтверждения.

### Исправлено

- Элементы на вкладках окна «Параметры приложения» снова доступны для мыши и клавиатурной навигации; страницы больше не изолируют их от обработки сообщений диалога.
- После закрытия окна «Настройки → Параметры приложения…» главная форма снова становится активной без принудительного изменения порядка окон и видимого мигания.
- Фон групп на вкладках окна настроек приведён к общему фону формы; серые системные области больше не выделяются относительно страницы.
- На вкладке «Данные» расширены кнопки управления путями и историей, чтобы их подписи отображались полностью.
- Контекстные меню больше не показывают недоступные команды; разделители и команды добавления для виртуальных корней выводятся только при наличии применимого действия.
- Значок команды «Теги» в контекстном меню сделан контрастнее и визуально отделён от текста.
- Для пунктов с вложенными подменю включена единая стандартная системная отрисовка стрелки во всех меню.
- Подменю «Теги» и «Недавно открытые списки» используют ту же разметку значков, что остальные команды; для «Теги» сохранена прежняя контурная пиктограмма, а стрелки подменю оставлены стандартной отрисовке Windows без дублирования.

- Очистка кэша корректно работает, когда системный корень `%APPDATA%` или `%LOCALAPPDATA%` представлен Windows через junction/alias; reparse point внутри разрешённого пути по-прежнему отклоняется.
- Протокол сохранения `ibases.v8i` больше не использует файловый handle цели,
  который приходилось закрывать перед `MoveFileExW`: именованный mutex IBStart
  удерживается до commit, а атомарная замена выполняется отдельной операцией.
  Добавлены тесты, которые меняют файл и запускают конкурирующее сохранение

  протокол; произвольные внешние программы могут не участвовать в mutex, и
  короткое окно TOCTOU для них явно считается остаточным ограничением Windows.

- Добавлено контекстное меню дерева с запуском, избранным, редактированием, очисткой кэша, ярлыком, удалением, добавлением в выбранную группу и перемещением вверх/вниз.
- Добавлены оригинальный значок IBStart, пиктограммы кнопок и элементов дерева, а сведения о выбранной базе оформлены как цветная двухколоночная карточка.
- Включён Common Controls v6: значки дерева теперь используют прозрачность без чёрного фона, а пиктограммы отображаются на кнопках; контекстное меню получило цветные значки для всех действий.
- Подписи кнопок теперь рассчитывают ширину по фактическому тексту, значку и DPI; дерево различает файловые и серверные базы отдельными яркими пиктограммами.
- Кнопки, поиск, дерево и таблица свойств используют масштабируемый Segoe UI с ClearType вместо системного растрового шрифта.
- Сочетания в контекстном меню вынесены в отдельную приглушённую колонку; добавлены работающие клавиатурные ускорители для всех его команд и подсказки комбинаций у основных кнопок.
- Единый редактор баз заменил ввод сырой строки `Connect`: доступны имя базы, файловое/веб/серверное подключение и параметры запуска; пользовательские диалоги центрируются относительно IBStart и используют тот же Segoe UI с ClearType.
- В параметрах запуска добавлена разрядность `AppArch`: только 32/64-bit и приоритет 32/64-bit; при запуске IBStart учитывает `AppArch`, а `/AppArch` из `AdditionalParameters` имеет более высокий приоритет.
- Добавлено окно «Дополнительные настройки базы» со справкой по служебным полям `ibases.v8i`, поддержкой `DefaultVersion` и `OrderInTree`; кнопки главного окна получили атомарную адаптивную раскладку без следов и наложений при изменении размера.
