# Проверка вложенных параметров конструктора

Дата: 2026-10-19. Ветка: `feat/launch-parameters-builder`.
Последующая проверка порядка и обязательности описана в
[отдельном протоколе](verification-launch-option-order.md).
Исходный конструктор: `970d9ae`; параллельная ревизия документации сохранена
в истории (`f30541b`, `7ac3039`).

## Охват сверки

Из 24 локальных разделов приложения 7 (8.3.6–8.3.27, 8.5.1, 8.5.4) получены:

- 250 версионных форм синтаксиса команд;
- 319 вариантов вложенных опций с учётом написания и способа передачи значения;
- 307 различных пар «команда + вложенная опция» без учёта регистра;
- 53 записи перечислений «команда + опция + значение» с масками версий.

В профиле 8.5.1 вложенные опции найдены у 58 команд, всего 294 опции.
Это включает параметры, описанные списком после синтаксиса. Полный набор
синтаксиса и идентификаторов компилируется в `parameter_grammar.inc`;
абзацы, HTML и примеры ИТС туда не переносятся. Собственные пояснения
размещены в `parameter_option_help.inc` и `parameter_options.cpp`.

## Поведение формы

У команд с вложенными опциями доступен список «Параметр команды». Значение
задаётся отдельно от имени параметра; флаг без операнда добавляется без
поля значения. Дополнительные опции дописываются в ту же команду.
Изменение и удаление опции сохраняет основные аргументы, соседние опции,
неизвестные фрагменты и окружающий текст.

Для 65 ранее справочных команд пакетного режима явно задан режим
Конфигуратора. В окне запуска Предприятия вставка таких команд недоступна;
введённая вручную строка получает ошибку режима. В самостоятельном
конструкторе без выбранного режима их можно составлять. Отсутствие
отдельных полей у команды само по себе не считается ошибкой её запуска.
Все 1403 появления этих 65 идентификаторов в коллекции относятся к разделу
пакетного запуска. Название и номер раздела различаются в старых версиях.
Нативный тест проверяет недоступность вставки в режиме Предприятия,
пояснение причины и сохранность исходной строки.

Команда `/ConfigurationRepositoryCreate` показывает все семь опций и
три значения каждого правила поддержки. Для `/SetPredefinedDataUpdate`
доступны три альтернативных режима; описаны действие каждого и различие
главного/периферийного узлов при `-Auto`. Параметры и значения выводятся
отдельными блоками с переносами строк. При выборе опции справка прокручивается
к её блоку. Начальный размер окна увеличен, области каталога и справки
сбалансированы для длинного синтаксиса.

## Проверки

- Release-сборка MSVC C++20 с `/W4 /WX`: PASS.
- Полный CTest, 5 групп: PASS.
- Проверки ядра обходят команды и профили и требуют пояснений для всех
  отображаемых опций и значений перечислений. Отдельно проверены полный
  набор создания хранилища, правила поддержки, отсутствие новых форм для
  неизвестной версии и раздельное представление аргументов запуска DESIGNER.
- Проверены сохранение неизвестных опций, пробелов и основных операндов,
  добавление нескольких параметров к одному родителю, изменение и удаление
  одного параметра, отказ от перезаписи неоднозначных повторов и слитный
  числовой операнд `-Call123`.
- Нативная проверка настоящей формы собирает все семь опций создания
  хранилища, выбирает правила поддержки, проверяет зависимую группу,
  удаляет один флаг и сохраняет соседние значения. Для предопределённых
  данных проверяет три варианта выбора и текст значения по умолчанию.
- Исправлен выявленный этой проверкой дефект: изменение строки через
  `WM_SETTEXT` у многострочного EDIT не вызывает `EN_CHANGE`, поэтому после
  структурированной вставки проверка теперь вызывается явно.
- Шесть синтетических Python-проверок извлечения: PASS. Проверены несколько
  опций, четыре способа передачи операнда, необязательное значение, границы
  команды и раздела, однострочное определение и исключение кодов возврата
  из перечисления значений последней опции.
- `python tools/update-parameter-grammar.py --check`: данные воспроизводятся
  из сохранённой коллекции; приложение для работы не требует этих файлов.
- Визуально просмотрена общая форма с длинным синтаксисом и отдельным блоком
  вложенной опции при масштабе 100%. Читаемость обоих конкретных примеров
  отдельно на всех масштабах Windows не подтверждалась; их содержимое и
  управление проверены нативным тестом.

## Границы

Это сверка документации и проверка IBStart. Создание настоящего хранилища,
реструктуризация базы и другие операции самой 1С не выполнялись.
Наличие идентификаторов в грамматике не означает полного семантического
валидатора всех пакетных операций. Повторяющиеся группы, например несколько
пар источников поставки, и нестандартные конструкции сохраняются для ручной
правки. Неизвестный профиль не наследует синтаксис соседней версии.

Сборка со встроенной справкой: 2 233 344 байт, около 2,13 МиБ. Дополнительный
файл справки для поставки не требуется.
