# Сверка версий документации 1С

Дата сверки документации: 2026-10-19.

Сформировано `tools/update-1c-reference.py` из [реестра источников](reference-data/1c-reference.json). Порядок повторной сверки: [обновление справочников](maintaining-1c-reference.md).

Наличие в документации, реализация IBStart и исполнение установленной платформой — отдельные факты. Диапазон начинается с первого проверенного определения, а не с доказанной версии появления функции. Сравниваются соседние **проверенные** версии; пропуски не заполняются.
