# Проверка справочника конфигураций — 0.8.0

Дата: 2026-10-20. Ветка: `feat/configuration-catalog`, создана от `847734a`
ветки конструктора параметров. Версия приложения остаётся `0.8.0`.

## Реализованный этап

- Отдельный `configurations.json`: постоянный ID, Имя, Наименование (синоним),
  Краткое наименование. Первичное заполнение — 13 записей шести семейств:
  Бухгалтерия, ЗУП, УТ, ERP, УНФ, Розница, с отдельными базовыми/КОРП-поставками.
- Редактор справочника, поиск по трём текстовым полям, добавление и переименование,
  запрет удаления записи со ссылками из любого сохранённого списка профиля.
- Конфигурация и ручная версия базы, поиск в выборе, вызов справочника из редактора.
- Поиск баз по имени/наименованиям конфигурации и версии, совместно с фильтром тегов.
- Независимая настройка меток, полные сведения в карточке и подсказке дерева.
- Импорт/экспорт трёх файлов профиля и совместимость со старым двухфайловым профилем.

Проверки ядра подтверждают сохранение версии, неизменность ID при переименовании
конфигурации, изоляцию одноимённых баз разных файлов списков, перенос связи при
переименовании базы, блокировку удаления используемой записи, импорт/экспорт,
отказ от импорта повреждённого справочника без изменения текущего профиля,
чтение старого профиля и отсутствие повторного добавления удалённых начальных записей.
Отдельно проверены поиск по всем новым полям и сочетание поиска с тегами.

`ibstart.parameter_dialog_contracts` проверяет сохранение полей запуска при редактировании
метаданных, отмену форм и редактор справочника на отдельном тестовом рабочем столе Windows.
Сохранены проверки конструктора: 23 команды без аргументов в 334 сочетаниях
команда/профиль и 26 команд с основными аргументами в 373 сочетаниях.

`ibstart.configuration_application_contracts` запускает настоящее главное окно
с отдельным временным профилем на отдельном рабочем столе Windows. Через окно редактирования
назначается УТ11 и версия `11.5.22.123`, затем проверяются сохранённая связь,
побайтная неизменность `ibases.v8i`, отсутствие новой `.bak_`-копии и поиск только
назначенной базы. Справочник открывается командой главного окна.

Снимки главного окна, редактора и справочника получены из работающего интерфейса
на синтетических данных и просмотрены. Они размещены в руководстве и на странице
возможностей. Клиент 1С не запускается; реальные базы и пользовательский профиль
в этих проверках не используются.

## Границы и следующие этапы

- Версия заполняется вручную. Получение сведений из базы, определение по Имени
  и проверка актуальных релизов пока не реализованы.
- Автоматическое определение должно учитывать возможное совпадение Имени у редакций.
- Область связи включает путь списка; перенос самого `ibases.v8i` в другой каталог
  требует повторного назначения. Внешнее удаление записей списка не очищает старые связи.
- Новый формат профиля нужно экспортировать перед возвратом к старой версии IBStart.
- Этот прогон не подтверждает полную матрицу масштабов/DPI и версий Windows,
  работу подключений к 1С или публикацию релиза.

Для выпуска 0.8.0 остаётся общая приёмка релизного набора и итоговый PR в `main`.
Merge, push и публикация релиза в рамках этой доработки не выполнялись.

## Табличный список — 2026-10-21, первый вариант

Склеенная подпись в справочнике заменена таблицей с колонками «Имя», «Наименование»
и «Краткое наименование». Добавлены заголовки, сетка, выделение всей строки,
изменение ширины колонок и подсказки для обрезанного текста. Клиентская ширина окна
увеличена с 780 до 1100 логических пикселей; поля редактирования остаются справа.
Порядок записей и поиск по трём реквизитам сохранены. Обновление таблицы при поиске
восстанавливает выбранную запись и не перезаполняет несохранённые поля редактора.

- Release MSVC C++20, `/W4 /WX`: PASS; `IBStart.exe` — 2 523 136 байт.
- CTest: 6/6 PASS. Проверены заголовки и отдельные значения ячеек, заполнение редактора

- Снимки работающего окна до и после изменения получены на отдельном рабочем столе

## Отдельное окно записи — 2026-10-21

Этот этап заменяет встроенные поля редактирования первого варианта. В справочнике
остались поиск, таблица и кнопки «Добавить…», «Изменить…», «Удалить». Ширина окна
справочника — 820 логических пикселей, таблица занимает всю доступную ширину.

«Добавить…» открывает модальное окно 480 × 272 логических пикселя с пустыми полями;
«Изменить…» — с тремя реквизитами выделенной записи. В нём находятся «Сохранить»
и «Отмена». Сохранение пишет данные через существующий сервис метаданных и закрывает
редактор только при успехе; ошибки оставляют форму открытой. Отмена и крестик
не записывают черновик. После сохранения список обновляется и выделяет запись.
Пока открыто окно записи, справочник недоступен; после закрытия он снова активен.
При отсутствии выделенной строки изменение, удаление и выбор недоступны.

Двойной щелчок в обычном справочнике открывает изменение. В справочнике выбора
из редактора базы он сохраняет прежнее назначение — подтверждает выбор конфигурации.

- Release MSVC C++20, `/W4 /WX`: PASS; `IBStart.exe` — 2 525 696 байт.
- UI-проверки на изолированных рабочих столах и временных профилях: PASS.
  Проверены пустые поля при добавлении, модальный владелец, сохранение новой записи,
  отмена добавления без изменения профиля, заполнение всех полей при изменении,
  закрытие изменённого черновика крестиком, сохранение изменения под прежним ID,
  сохранность связи с базой и её версии, обновление строки таблицы, доступность
  кнопок после фильтрации и отмены, оба назначения двойного щелчка.
- Снимки до изменения: `out/verification/configuration-columns-after/`.
  Снимки текущего справочника, пустого добавления и заполненного изменения:
  `out/verification/configuration-record-editor/`; все три просмотрены.
  Иллюстрации руководства обновлены.
- Полный CTest: 6/6 PASS, включая обе UI-проверки.
- `mkdocs build --strict`: PASS с подготовкой и последующим удалением временной
  `docs/changelog.md`, как в workflow Pages.
- `git diff --check`: PASS.

Проверки не используют реальные базы или пользовательский профиль и не запускают 1С.
Полная матрица DPI и малых экранов остаётся вне этого прогона.
