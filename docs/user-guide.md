# Краткое руководство пользователя

## Сведения о программе

Точная версия установленного IBStart отображается через **Справка → О программе**. Та же версия записана в свойства `IBStart.exe` и совпадает с тегом соответствующего GitHub Release.

## Выбор списка

После старта в нижней строке отображаются путь к активному списку, число найденных баз и число обнаруженных платформ 1С. Чтобы переключиться на другой список, выберите **Файл → Открыть список баз**. При первом сохранении IBStart создаёт резервную копию рядом с исходным файлом; стандартный стартер 1С увидит изменения после обновления своего списка.

## Базы и группы

**Добавить файловую базу** принимает только каталог, где есть `1Cv8.1CD`. Это проверка, а не создание базы. Группы допускают любую вложенность. Удаление секции не удаляет файлы базы. Для изменения `Connect` выберите базу и нажмите **Изменить**. При конфликте с другой программой соглашайтесь на перечитывание, а затем повторяйте изменение.

Перетаскивание элемента на группу меняет его `Folder`, а новый порядок фиксируется `OrderInList`.

Щёлкните базу или группу правой кнопкой мыши, чтобы открыть контекстное меню. Для базы доступны запуск Предприятия и Конфигуратора, избранное, изменение, очистка кэша, ярлык, перемещение вверх/вниз и удаление записи. Для группы доступны изменение, перемещение, удаление и добавление новых баз или вложенной группы непосредственно внутрь неё. Щелчок правой кнопкой по пустому месту позволяет добавить элемент в корень и обновить список.

Справа имя и тип выбранного элемента выводятся отдельным заголовком, а поля `ibases.v8i` — в двухколоночной карточке с понятными русскими названиями. Исходные ключи и значения при этом не изменяются.

Поле **Поиск** фильтрует дерево без учёта регистра: запрос `кд` находит имена с `КД`. Каждый совпавший фрагмент имени выделяется светло-зелёным фоном и тёмно-зелёным текстом; родительские группы остаются в дереве, чтобы был виден путь к найденной базе.

Значок записи в дереве показывает тип подключения: зелёная база с документом — файловая база (`File=`), фиолетовая стойка с сетевыми узлами — серверная или иной сетевой тип подключения. Жёлтая папка обозначает группу. Основные кнопки имеют пиктограммы, но их подписи не обрезаются: окно не даёт уменьшить ширину ниже размера, необходимого для полного текста.

## Запуск

Выберите базу и используйте **F3** для Предприятия или **F4** для Конфигуратора. IBStart ищет установленный клиент самостоятельно; «Авто» выбирает x64 раньше x86. Если нужной версии нет, запуск отменяется с сообщением.

Для веб-подключения, распознанного как `http://`/`https://`, открывается браузер. «Создать ярлык» сохраняет на Рабочий стол ярлык на IBStart с идентификатором базы, но без пароля.

## Параметры и кэш

Дополнительные параметры остаются в `AdditionalParameters` и передаются совместимо с аргументами клиента. Не храните пароль через `/P`: он может быть виден в файле списка. В журнал он не попадёт в открытом виде.

«Очистить кэш» сначала показывает точный список известных cache-папок. Закройте процессы 1С, подтвердите операцию и проверьте результат в сообщении/логе. Каталог файловой базы не является допустимой целью этой команды.

## Простой режим

Меню **Вид → Простой режим** скрывает изменение списка и очистку кэша. Это настройка удобства для пользователя, а не механизм защиты от действий в файловой системе.
