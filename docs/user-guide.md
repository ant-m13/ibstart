# Краткое руководство пользователя

## Сведения о программе

Точная версия установленного IBStart отображается через **Справка → О программе**. Та же версия записана в свойства `IBStart.exe` и совпадает с тегом соответствующего GitHub Release.

## Выбор списка

После старта в нижней строке отображаются путь к активному списку, число найденных баз и число обнаруженных платформ 1С. Чтобы переключиться на другой список, выберите **Файл → Открыть список баз**, **Открыть стандартный список 1С** или один из пунктов **Недавно открытые списки**. При первом сохранении IBStart создаёт резервную копию рядом с исходным файлом; стандартный стартер 1С увидит изменения после обновления своего списка.

## Базы и группы

Окно **Добавление информационной базы** и **Редактирование информационной базы** открываются относительно главного окна, а не в углу рабочего стола. В них используется тот же масштабируемый `Segoe UI` с ClearType, что и в основном окне.

В редакторе задаются имя в списке и тип расположения: каталог файловой базы, адрес веб-сервера или кластер и имя серверной базы. Для файловой базы кнопка **Обзор…** выбирает каталог; при добавлении он должен содержать `1Cv8.1CD`. Это проверка существующей базы, а не создание новой. Группы допускают любую вложенность, а удаление секции не удаляет файлы базы.

Кнопка **Дополнительные настройки…** открывает отдельное окно со служебными полями формата `ibases.v8i`: `DefaultApp`, `DefaultVersion`, `ID`, `Folder`, `OrderInList`, `OrderInTree`, `External`, `Locale` и `AdditionalParameters`. Возле каждого поля есть кнопка **?** с кратким объяснением. `ID` и `Folder` показываются только для справки: идентификатор должен оставаться уникальным, а расположение в группе меняется перетаскиванием или командами перемещения. `OrderInTree` учитывается при построении дерева; при перемещении IBStart синхронно обновляет `OrderInList` и `OrderInTree`.

Ниже находятся параметры запуска из `ibases.v8i`: версия платформы, разрядность, режим клиента, приложение по умолчанию, аутентификация ОС, флаг внешней базы, локаль, скорость соединения и дополнительные параметры. Разрядность имеет варианты «Только 32 (`x86`)», «Только 64 (`x86_64`)», «Приоритет 32 (`x86_prt`)» и «Приоритет 64 (`x86_64_prt`)»; значение сохраняется в `AppArch`. При запуске IBStart учитывает это поле. Если в `AdditionalParameters` задан `/AppArch`, он имеет приоритет над `AppArch`, как и в стандартном стартере 1С. В поле «Версия платформы» можно указать как полную версию, так и её начало — например, `8.3.27` сопоставится с установленной `8.3.27.1688`.

Версия платформы, разрядность, тонкий клиент и дополнительные параметры учитываются при запуске из IBStart; остальные поля сохраняются совместимо со стандартным стартером 1С. Неизвестные части исходной строки `Connect` не удаляются при смене адреса или пути.

Перетаскивание элемента на группу меняет его `Folder`, а новый порядок фиксируется `OrderInList`.

Щёлкните базу или группу правой кнопкой мыши, чтобы открыть контекстное меню. Для базы доступны запуск Предприятия и Конфигуратора, избранное, изменение, очистка кэша, создание ярлыка, открытие папки файловой базы в проводнике, перемещение вверх/вниз и удаление записи. Для группы доступны изменение, перемещение, удаление и добавление новых баз или вложенной группы непосредственно внутрь неё. В разделе «Недавние» команда «Очистить недавние базы…» удаляет только историю запусков, не затрагивая сами базы и избранное; она также доступна через **Вид → Очистить недавние базы…**. Щелчок правой кнопкой по пустому месту позволяет добавить элемент в корень и обновить список. После **Обновить список** или `F5` выбранная база или группа остаётся активной, если запись всё ещё есть в файле.

Названия команд в нём расположены слева, а сочетания клавиш — отдельной приглушённой колонкой справа: они не сливаются с текстом и остаются читаемыми при выделении пункта. Те же комбинации действуют, когда меню закрыто; при наведении на основную кнопку показывается её сочетание.

| Команда | Сочетание |
| --- | --- |
| Предприятие / Конфигуратор | `F3` / `F4` |
| Изменить | `F2` |
| Добавить или убрать из избранного | `Ctrl+Alt+I` |
| Очистить недавние базы | **Вид → Очистить недавние базы…** |
| Очистить кэш / Создать ярлык | `Ctrl+Shift+Del` / `Ctrl+Shift+S` |
| Копировать значение параметра | `Ctrl+C` в таблице сведений |
| Открыть папку файловой базы | `Ctrl+Shift+O` |
| Переместить вверх / вниз | `Ctrl+Shift+Up` / `Ctrl+Shift+Down` |
| Удалить | `Alt+Shift+Del` |
| Добавить файловую базу / серверную базу / группу | `Ctrl+Alt+F` / `Ctrl+Alt+S` / `Ctrl+Alt+G` |
| Обновить список | `F5` |
| Открыть список баз | `Ctrl+O` |
| Переключить простой режим | `Ctrl+Alt+M` |
| Перейти к поиску | `Ctrl+F` |
| О программе | `F1` |

Справа имя и тип выбранного элемента выводятся отдельным заголовком, а поля `ibases.v8i` — в двухколоночной карточке с понятными русскими названиями. Исходные ключи и значения при этом не изменяются.

Поле **Поиск** фильтрует дерево без учёта регистра по всем реквизитам базы и её тегам: имени, пути файловой базы, серверу, строке подключения и другим полям списка. Запрос `кд` находит имена с `КД`, а `cluster-01` — базы с таким сервером 1С. Каждый совпавший фрагмент имени выделяется светло-зелёным фоном и тёмно-зелёным текстом; совпадение в цветной метке тега выделяется жирным. Если обычный показ меток отключён, найденная по тегу метка всё равно кратко выводится рядом с подходящей базой. Родительские группы остаются в дереве, чтобы был виден путь к найденной базе.

Теги хранятся в `catalog-state.json`, привязаны к `ID` базы и не меняют `ibases.v8i`. Все команды для них собраны в подменю **Теги** контекстного меню базы: **Управление тегами…** открывает форму назначения, а ниже можно сразу присвоить один из доступных тегов, создать новый тег или открыть общую настройку. Такая же команда доступна в основном меню **Вид** как **Управление тегами выбранной базы…**. Форма назначения заменяет строку «через запятую»: отметьте нужные существующие теги флажками или введите новый и нажмите **Добавить и отметить**. Через **Вид → Настроить теги…** открывается единая форма создания, переименования и удаления тегов; для фона и текста доступны кнопки выбора из палитры, а готовая метка отображается в живом предпросмотре. Переименование и удаление сразу применяются ко всем базам с этим тегом.

Цветные метки тегов показываются рядом с названиями баз в дереве и отдельными строками в карточке. Если метки не помещаются в строку, после последних поместившихся выводится компактная метка **…**; наведите указатель на базу, чтобы увидеть в подсказке полный список её тегов. Их можно скрыть через **Вид → Показывать теги в списке баз**; сами теги и фильтрация при этом остаются доступными. Отдельное поле **Фильтр по тегу** оставляет в дереве все базы, избранные или базы с конкретным тегом. Отдельный виртуальный раздел **Избранное** выводится в самом верху дерева, перед **Недавними** и обычным каталогом.

Список **Сортировка** задаёт общий порядок: исходный, по названию или по последнему запуску. Для отдельной папки откройте её контекстное меню и выберите **Сортировка в этой папке**; пункт «Как для всего списка» отменяет её индивидуальную настройку. Ручная перестановка и перетаскивание доступны только при исходном порядке, чтобы действие сразу было видно. В контекстном меню базы команда **Переместить в папку…** открывает дерево групп для выбора назначения. При перетаскивании название базы следует за курсором: наведите его на группу, чтобы перенести запись внутрь, на верхнюю или нижнюю часть другой записи — чтобы вставить перед ней или после неё, либо на свободное место дерева — чтобы перенести в корень списка. Даты запусков хранятся локально в `catalog-state.json`, поэтому очистка раздела «Недавние» не меняет сортировку по последнему запуску.

Дополнительные сведения о базе выводятся в той же правой карточке, без отдельного окна и отделены от параметров подключения. У файловой базы это каталог, полный путь к `1Cv8.1CD`, его размер и дата изменения; сведения читаются только с локального диска. У клиент-серверной базы показаны сервер 1С и имя базы из `Srvr`/`Ref`. Размер и прочие сведения, требующие подключения к SQL Server, приложение не запрашивает.

Значок записи в дереве показывает тип подключения: зелёная база с документом — файловая база (`File=`), фиолетовая стойка с сетевыми узлами — серверная или иной сетевой тип подключения. Жёлтая папка обозначает группу. Основные кнопки имеют пиктограммы, но их подписи не обрезаются: окно не даёт уменьшить ширину ниже размера, необходимого для полного текста.

Для читаемости на обычных и HiDPI-экранах кнопки используют `Segoe UI Semibold`, а поиск, дерево и таблица свойств — обычный `Segoe UI`; оба шрифта создаются с ClearType и масштабируются вместе с окном.

## Запуск

Выберите базу и используйте **F3** для Предприятия или **F4** для Конфигуратора. IBStart ищет установленный клиент самостоятельно; «Авто» выбирает x64 раньше x86. Если нужной версии нет, запуск отменяется с сообщением.

Для веб-подключения, распознанного как `http://`/`https://`, открывается браузер. «Создать ярлык» сохраняет на Рабочий стол ярлык на IBStart с идентификатором базы, но без пароля.

## Параметры и кэш

Дополнительные параметры остаются в `AdditionalParameters` и передаются совместимо с аргументами клиента. Не храните пароль через `/P`: он может быть виден в файле списка. В журнал он не попадёт в открытом виде.

В таблице сведений выделите параметр и нажмите `Ctrl+C`, чтобы скопировать его значение. Контекстное меню таблицы также позволяет скопировать параметр вместе со значением.

«Очистить кэш» сначала показывает точный список известных cache-папок, размер каждой из них и общий примерный объём для очистки. Проверяются каталоги `%APPDATA%\1C\1Cv8\<ID>` и `%LOCALAPPDATA%\1C\1Cv8\<ID>` (где `<ID>` — идентификатор базы из поля `ID`, иначе её имя), а также собственный каталог `%LOCALAPPDATA%\IBStart\cache\<ID>`. Закройте процессы 1С, подтвердите операцию и проверьте результат в сообщении/логе: освобождённое место отображается в Б, КБ, МБ или ГБ. Каталог файловой базы не является допустимой целью этой команды.

## Простой режим

Меню **Вид → Простой режим** оставляет компактный рабочий экран: поиск, дерево баз, строку подключения выбранной базы и кнопки **Предприятие** и **Конфигуратор**. Скрываются карточка выбранной базы, теги, фильтр по тегам и сортировка. Остальные основные действия с выбранной базой остаются в контекстном меню дерева: **Изменить**, **Удалить**, **Переместить в папку…**, **Переместить вверх** и **Переместить вниз**. В верхнем меню остаётся только пункт **Режим → Выйти из простого режима** (также работает `Ctrl+Alt+M`); после выхода обычные элементы и команды возвращаются. Это настройка удобства для пользователя, а не механизм защиты от действий в файловой системе.
