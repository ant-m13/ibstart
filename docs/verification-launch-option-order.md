# Проверка порядка и обязательности параметров конструктора

Дата: 2026-10-19. Ветка: `feat/launch-parameters-builder`.

Последующая [сверка полных описаний](verification-launch-help-its.md)
уточнила число опций и исключения обязательности: у имени архива пакета
есть значение по умолчанию. Цифры ниже относятся к первоначальной проверке.

## Причина исправления

У `/Proxy` список опций сортировался по имени, а редактирование дописывало
каждую новую опцию в конец команды. Наличие обязательных опций и вложенные
скобки синтаксиса не проверялись. Обязательность значения опции уже учитывалась,
но это не заменяет проверку наличия самой опции.

## Охват

Повторно обработаны все 24 версии приложения 7: 8.3.6–8.3.27,
8.5.1 и 8.5.4. Данные встроены в EXE и воспроизводятся из документации.
В ней 250 форм синтаксиса, 307 различных пар «команда + опция» без учёта
регистра и 53 записи значений. С учётом положения в разных профилях хранится
442 варианта опций. Получены 33 правила обязательности/зависимостей и
30 пар несовместимых вариантов с масками версий.

Из синтаксиса извлекаются обязательные основные аргументы, обязательные
опции, необязательные группы, вложенные группы и альтернативы. Внутренние
скобки и вертикальные черты операнда не становятся альтернативами опций.
Для повторяемой группы варианты не считаются взаимно исключающими.
Для всех правил проверяется наличие упомянутых опций в том же профиле.

Примеры проверяемых требований:

| Команда | Требование |
| --- | --- |
| `/Proxy` | `-PSrv`, `-PPort`; пароль требует пользователя |
| `/MergeCfg`, `/UpdateCfg` | основные аргументы и `-Settings`; альтернативы обработки ссылок |
| `/CompareCfg` | два типа конфигураций, тип отчёта, формат и файл отчёта |
| `/ConfigurationRepositoryAddUser` | пользователь, пароль и права; явный пустой пароль допустим |
| `/ConfigurationRepositoryCopyUsers` | путь, пользователь и пароль |
| `/ConfigurationRepositoryCreate` | совместное задание разрешения изменений и обоих правил поддержки |
| `/CreateDistributive`, `/CreateDistributivePackage` | файл описания; имя архива пакета необязательно согласно подробному тексту (`updsetup.zip`) |
| `/SignCfg` | обязательные параметры зависят от профиля; старый `-Type` и новый `-ConfigurationType` различаются |
| `/DumpConfigToFiles` | вложенный `-JobsCount` требует `-Server` |
| `/UpdateDBCfg` | вложенный `-Visible` требует `-BackgroundFinish`; `-v1` и `-v2` исключают друг друга |
| `/CreateDistributionFiles` | группа обновления требует `-cfufile` и одного из источников `-f`/`-v`; источники могут повторяться |
| `/ConfigurationRepositorySetLabel` | имя метки обязательно, написание `-name` перед ним необязательно |

Заголовок `/LoadConfigFromFiles` уточнён по описаниям его опций: полная
загрузка допустима без `-files`, `-listFile`, `-Format`, `-partial`.
Каталог загрузки и `-Archive` являются альтернативами. Совместное указание
`-files` и `-listFile` оставляется для ручной правки: документация задаёт
приоритет первого, поэтому конструктор не меняет его автоматически.

## Поведение редактирования

Список выбора и структурированная вставка используют порядок выбранной
версии. При редактировании переставляются целые фрагменты «опция + значение»;
кавычки, значения соседних опций, основные аргументы, неизвестные фрагменты
и окружающие пробелы сохраняются. Повторяющиеся группы не переставляются,
включая несколько источников `-f`/`-v` у `/CreateDistributionFiles`.
Само открытие формы, ручной ввод и подтверждение без структурированной
правки не нормализуют строку.

Звёздочка помечает безусловно обязательные опции и опции, ставшие обязательными
из-за уже выбранных. Условия отображаются в описании. Группа «один из вариантов»
объясняется текстом и проверяется без обозначения каждого варианта как
отдельно обязательного. Основные аргументы в списке тоже получают метку.

Дополнительно исправлен разбор слитных имён: `-DynamicRestruct` в 8.5.4
не принимается за `-Dynamic` с операндом. Учтены значения, записанные
в типографских кавычках без угловых скобок, например `-Z`.

## Проверки

- Release, MSVC `/W4 /WX`: PASS.
- CTest: 5/5 PASS, включая тест реальной нативной формы.
- Python: 23/23 PASS во всей коллекции тестов инструментов; 15 из них
  проверяют грамматику команд.
- `python tools/update-parameter-grammar.py --check`: PASS по всем 24 профилям.
- Проверка порядка обходит все профили и команды с редактируемыми вложенными
  опциями: перестановка обратного порядка, сохранение значений и повторная
  правка без дальнейшего изменения результата.
- `/Proxy` проверен во всех профилях: отсутствие адреса/порта, зависимость
  пароля, пустой пароль, ввод опций в обратном порядке, перестановка уже
  составленной строки, сохранение кавычек и неизвестного фрагмента.
- Нативная форма проверяет порядок списка, метки обязательности, заполнение
  прокси в обратном порядке, недоступность «Применить» при пропусках,
  восстановление доступности и удаление зависимого пользователя.
- Проверены обязательные аргументы у команды без вложенных опций (`/DumpIB`),
  имя метки с `-name` и без него, альтернативы загрузки из каталога/архива,
  зависимые и несовместимые опции, границы неизвестного профиля.

Размер EXE: 2 274 304 байта, около 2,17 МиБ.

## Границы подтверждения

Проверены документация и поведение IBStart. Реальные операции 1С и принятие
платформой произвольного порядка опций не проверялись. Порядок конструктора
соответствует справочнику; это не утверждение, что иной порядок всегда
отклоняется самой платформой. Условные требования, зависящие от содержимого
конфигурации или значений отдельных опций, не образуют полного семантического
валидатора платформы. Неизвестные и повторяющиеся конструкции сохраняются
для ручного редактирования.
