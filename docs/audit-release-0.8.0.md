## Вывод

После основного аудита по пользовательским снимкам дополнительно исправлено
[выравнивание кнопок конструктора](verification-launch-button-alignment.md).
По замечанию ревью PR #16 исправлены
[кавычки одиночных основных аргументов](verification-launch-primary-quoting.md)
и проверены остальные редакторы значений.
Сведения и контрольная сумма основного аудита ниже относятся к его исходному
артефакту; актуальная сборка после правки расположения формируется отдельно.

После исправлений перечисленные локальные проверки пройдены. Локальная
сборка готова к передаче на проверку PR и последующий выпуск по
[процессу публикации](release-process.md). Это не подтверждение прохождения
удалённых CI/CodeQL и не публикация версии. Отсутствие всех возможных ошибок
не может быть доказано этим аудитом; непроверенные условия перечислены ниже.

## Объём проверки

Изучены изменения относительно `v0.7.8`: конструктор и грамматика параметров,
проверка запуска и выбора архитектуры, редакторы и возврат/отмена диалогов,
справочник конфигураций, привязки и ручные версии, поиск и отображение,
трёхфайловый профиль, стартовая проверка обновлений, меню и ресурсы,
генераторы справочной документации и сценарии сборки/публикации.
Генерируемые справочники проверены на воспроизводимость; это не исполнение
каждой команды во всех версиях 1С.

## Найденные проблемы и исправления

| Проблема | Основание | Результат |
| --- | --- | --- |
| Конструктор создаёт допустимый `/P ""`, а окончательная проверка считает его отсутствующим значением | Новый регрессионный сценарий сначала завершился сообщением «У параметра /P отсутствует значение» | Явное пустое значение разрешено; `/P` без аргумента, `/P /L ru` и пустое имя пользователя по-прежнему отклоняются. Проверен состав команды без запуска клиента. |
| Проверка остатков импорта учитывает только текущий PID и пропускает незавершённую операцию прежнего процесса | Новый сценарий воспроизвёл пропуск трёх видов файлов прежнего процесса при импорте и экспорте | Обе операции проверяют источник и назначение по всем суффиксам PID, отклоняют сомнительный профиль и сохраняют файлы восстановления. Проверены неизменность назначения и сохранность остаточных файлов. |
| Импорт без учётных записей читает текущие пароли до захвата блокировки замены профиля | Анализ промежутка между чтением и заменой: другой экземпляр мог сохранить учётную запись в этом промежутке | Чтение актуальных учётных записей и замена профиля выполняются под одной блокировкой назначения. Обычные сценарии импорта и сохранения записей проходят; отдельная детерминированная гонка этого промежутка не моделировалась. |
| В Windows CI ранняя ошибка генератора могла скрываться за успешной последней Python-командой | В локальном PowerShell последовательность кодов 17 и 0 завершилась кодом 0; поведение оболочки сверено с документацией GitHub | В `build.yml` и `release.yml` проверяется код каждой команды. Для обоих шагов отдельно проверены успешный путь и ошибка в каждой из трёх позиций. |
| Значок сайта отсутствовал в явных зависимостях RC-ресурса | Анализ списка ресурсов CMake | Добавлена зависимость `website.ico`; наличие подтверждено запросом графа Ninja. |

Проверка ошибок оболочки основана на
[правилах GitHub Actions](https://docs.github.com/en/actions/reference/workflows-and-actions/workflow-syntax#exit-codes-and-error-action-preference):
шаг PowerShell возвращает последний код внешней команды, поэтому одного
общего завершения шага недостаточно для нескольких последовательных проверок.

## Будущие возможности и действующие ограничения

В [плане развития](future-features.md) введены статусы и отдельные задачи:
CFG-02 — чтение сведений из базы, CFG-03 — актуальные релизы,
LAUNCH-01 — применение дополнительных полей списка при запуске,
LAUNCH-02 — самостоятельные операции администрирования.
Для CFG-02 подготовлен [бриф](planned-database-inspection.md) с границами,
критериями приёмки и открытыми вопросами. Новые COM-соединения и изменения
формата профиля ради будущей возможности в этот выпуск не добавлялись.

- В 0.8.0 конфигурация и её версия у базы заполняются вручную.
  Версия платформы не является версией прикладной конфигурации.
- `WA`, `ClientConnectionSpeed` и `Locale` сохраняются как поля списка,
  но не преобразуются IBStart в аргументы запуска. Это существующее
  ограничение, выделенное в LAUNCH-01; оно не исправлено данным аудитом.
  Доступные параметры командной строки можно указать явно, учитывая контекст
  и версию платформы.
- Откат трёх файлов профиля при обычной ошибке не обеспечивает общей
  атомарности при отключении питания; автоматическое восстановление
  незавершённого импорта отсутствует. Остатки операции сохраняются.
- Тесты не подтверждают работу со всеми реальными конфигурациями, расширениями,
  средствами аутентификации, сетевыми ресурсами и установленными платформами.
  Рабочие базы и пользовательский профиль в этой проверке не использовались.
- Не проверена полная матрица Windows 10/11, DPI, высокой контрастности
  и удалённых рабочих столов. COM-чтение из 1С не реализовано и не проверялось.
