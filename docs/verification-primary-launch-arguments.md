# Имена основных аргументов и пояснение загрузки из файлов

Дата: 2026-10-19. Ветка: `feat/launch-parameters-builder`.

## Дополнение от 2026-10-20: команды без вложенных опций

Обнаружена ошибка формы: основной аргумент добавлялся в редактор только при
непустом перечне вложенных опций. Поэтому `/EmailAuth <email>` и другие команды
без таких опций оставались без поля ввода, хотя их синтаксис был известен.
Предыдущие проверки имени аргумента не проверяли эту ветвь отображения формы.

Условие исправлено для всех команд с основными аргументами. Редактор использует
точный профиль выбранной версии независимо от наличия именованных опций.
Справка больше не сообщает об отсутствии полей при наличии основного аргумента.
Имена, кавычки, несколько позиционных аргументов и необязательность сохранены.

- В настоящей форме проверены 26 команд в 373 сочетаниях с 24 профилями.
  Для каждой проверены видимость и доступность ввода, наличие аргумента в
  списке и отсутствие сообщения о недоступном редакторе.
- Для `/EmailAuth` проверены имя `email`, обязательность, добавление адреса,
  замена прежнего значения и возможность применения корректной строки.
  В профиле 8.3.26 команда остаётся недоступной.
- Проверки ядра обходят эти же профили: чтение и изменение аргументов,
  сохранение соседних команд, обязательность и точное соответствие версии.
  Неизвестные семейства не получают профиль соседней версии.
- Release MSVC `/W4 /WX`: PASS; CTest: 5/5 PASS; Python: 44/44 PASS;
  строгая сборка документации: PASS. Проверка формы не запускает клиент 1С
  и не отправляет письма.

Проверенные команды с основными аргументами без вложенных опций:

| Группа | Команды |
| --- | --- |
| Клиент | `/EmailAuth`, `/URL`, `/RunShortcut`, `/Execute`, `/@`, `/AppCaption`, `/AppShortCaption` |
| Добавление базы | `/AddInList`, `/AddToList`, `/UseTemplate` |
| Агент | `/AgentBaseDir`, `/AgentListenAddress`, `/AgentPort`, `/AgentSSHHostKey` |
| Конфигуратор | `/ConvertFiles`, `/DumpIB`, `/RestoreIB`, `/DumpResult`, `/UpdateCfg`, `/ModuleGetSourceCodeAccess`, `/ModuleSetSourceCodeAccess`, `/DumpExternalDataProcessorOrReportToFiles`, `/LoadExternalDataProcessorOrReportFromFiles` |
| Мобильные команды | `/MAWriteFile`, `/MobileAppWriteFile`, `/MobileClientWriteFile` |

Охват включает исторические формы, в которых опции отсутствуют, и современные
формы, в которых они уже есть. Не каждая строка доступна в каждом профиле.

Снимок формы с `/EmailAuth` просмотрен: поле `email *`, введённый адрес и
итоговая команда видны, кнопка применения доступна. Результаты ниже относятся
к первоначальной проверке от 2026-10-19.

## Изменения

- Вместо общего пункта «Основные аргументы» форма показывает имена из
  встроенного синтаксиса выбранной версии без угловых скобок.
  Пример: `каталог загрузки *`. Несколько имён перечисляются через `;`.
  У одиночного аргумента то же имя показано у поля ввода.
- Строка имени хранится в состоянии окна, поэтому ссылка на неё остаётся
  действительной при смене выбранной опции. Способ ввода, кавычки,
  обязательность и альтернатива каталога/архива сохранены.
- Собственное пояснение `/LoadConfigFromFiles` теперь содержит запрет
  загрузки расширения вместо основной конфигурации и обратной операции.
- В 22 профилях (8.3.7–8.3.27, 8.5.1) описание различает автоматическое
  распознавание формата при полной загрузке и явный формат при частичной.
  Для `-files`/`-listFile` добавлено условное требование `-Format`.
- В 8.3.6 такого текста нет; сведения из более позднего профиля в него
  не добавлены. В 8.5.4 вводный текст упоминает `-Format`, но синтаксис
  и список опций его не содержат. Это противоречие описано в форме;
  отсутствующая опция не наследуется из 8.5.1.
- Исправлено чтение значения `-files` в старых заголовках с кавычками
  `“<файлы>”`: это опция со значением, а не флаг.

Пояснения остаются собственным текстом программы, а не копиями страниц.
При этом сокращение не должно терять существенные условия использования.
Полного повторного аудита содержания всех остальных собственных пояснений
в рамках этого исправления не выполнялось.

## Проверки

- Release MSVC `/W4 /WX`: PASS; EXE 2 276 864 байта, около 2,17 МиБ.
- CTest: 5/5 PASS.
- Python: 24/24 PASS; 16 тестов грамматики команд и 8 тестов других
  инструментов обновления справочников.
- Генерация по 24 профилям: 250 форм синтаксиса, 441 вариант опций с учётом
  позиции, 53 записи значений, 34 правила наличия и 30 несовместимых пар.
- Имена и ограничения описания проверены по всем 24 профилям; отдельно
  проверены неизвестный профиль, необязательный аргумент и несколько имён.
- Нативная форма: имя аргумента и поля ввода, вставка каталога с пробелом,
  условная метка `-Format`, недоступность применения без формата,
  применение после его заполнения, замена каталога архивом.
- Полная загрузка без `-Format` остаётся допустимой. Частичная загрузка
  проверена с `-files` и `-listFile` и обоими форматами из справочника.

Операции загрузки в самой 1С не выполнялись. Проверены данные справочника,
содержание встроенной справки и поведение конструктора IBStart.
