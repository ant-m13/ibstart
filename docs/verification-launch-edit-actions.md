# Параметры подключения и действия над добавленной командой

Дата: 2026-10-20. Ветка: `feat/launch-parameters-builder`.

## Поведение

- `/F`, `/S`, `/WS`, `/IBName`, `/IBConnectionString` получили редактор значения.
  Контекст отдельно разрешает их составление в самостоятельной форме.
  При возврате в дополнительные параметры базы разрешение не устанавливается:
  поле и вставка заблокированы, справка объясняет, что подключение задаётся
  в настройках базы. Ручной ввод также не проходит проверку применения;
  существующая проверка реального запуска остаётся обязательной.
- Отсутствующая обычная команда предлагает «Добавить в строку».
  Добавленный флаг без значения, например `/DisableStartupMessages`,
  предлагает «Удалить из строки». У команды со значением остаётся изменение
  и появляется отдельное удаление. Наличие команды повторно проверяется
  при действии; подписи и доступность обновляются и при ручном вводе.
- Для уже добавленной вложенной опции без значения основная кнопка показывает
  «Параметр добавлен» и отключена; удаление выполняется существующей «Убрать».
- Удалить можно и распознанную команду, недопустимую в текущем контексте,
  чтобы исправить ошибочную строку. Это не разрешает её вставку или изменение.
  Повторы, дополнительные неизвестные аргументы и незакрытые кавычки требуют
  ручной правки.

`RemoveLaunchParameter` удаляет только единственный структурированный фрагмент.
Окружающие пробелы, табуляции, неизвестные команды, кавычки и значения соседей
сохраняются. Текст `/DisableStartupMessages` внутри значения `/C` не является
удаляемой командой. Удаление `/Out` включает принадлежащий ему `-NoTruncate`.
Удаление последней команды может оставить введённые пользователем пробелы;
разделители намеренно не нормализуются.

## Проверки

- Проверки ядра: все пять подключений в обоих контекстах; значения с пробелами
  и вложенными кавычками; удаление флага и команды со значением, отсутствие
  подмены внутри кавычек, сохранение разделителей и неизвестных команд;
  отказ от удаления неоднозначных фрагментов.
- Настоящая Win32-форма: самостоятельная вставка/изменение/удаление подключений,
  запрет подключения при обоих вызовах из базы, запрет применения ручного `/F`,
  возможность удалить его для исправления. Флаги и команды со значением
  проверяются в самостоятельной форме, разовом запуске и настройках базы;
  отдельно проверяется обновление действий при ручном вводе.
- Снимки собственных синтетических форм создаются с `--capture` в
  `out/ui-parameter-builder/edit-actions/`; реальные базы и платформы не
  используются, профиль пользователя не изменяется.
