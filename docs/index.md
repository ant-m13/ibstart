## Менеджер запуска 1С для Windows

**IBStart (ИБ Старт)** — лёгкое нативное приложение для просмотра списка информационных баз из `ibases.v8i` и запуска установленных клиентов 1С:Предприятие 8.3/8.5.

## Основные возможности

<div class="feature-grid" markdown>

<div class="feature-card" markdown>
### Быстрый запуск
Запуск **Предприятия** и **Конфигуратора**, избранные базы, недавние запуски и горячие клавиши.
</div>

<div class="feature-card" markdown>
### Параметры запуска
Разовый запуск с выбором платформы, клиента, разрядности и учётной записи. Конструктор команд с встроенной справкой по версиям 1С.
</div>

<div class="feature-card" markdown>
### Работа со списком баз
Группы, файловые, серверные и веб-базы, поиск, теги, сортировка и безопасное сохранение `ibases.v8i`.
</div>

<div class="feature-card" markdown>
### Кэш 1С
Безопасная очистка известных каталогов кэша и фоновый расчёт размеров для базы, папки или всего списка.
</div>

<div class="feature-card" markdown>
### Portable mode
Работа как обычное приложение или переносимый режим с настройками IBStart в каталоге рядом с EXE.
</div>

<div class="feature-card" markdown>
### Проверка обновлений
Фоновая проверка при запуске сообщает о новой версии пунктом меню без всплывающих окон. Её можно отключить в настройках; ручная проверка остаётся доступной.
</div>

</div>

## Что нового

В **0.8.0** добавлены [конструктор параметров запуска](features.md#конструктор-параметров-запуска),
[справочник конфигураций и ручные версии баз](features.md#конфигурации-и-версии),
а также отключаемая фоновая проверка обновлений при запуске.
Конструктор доступен из дополнительных параметров и главного меню, показывает справку
по выбранной версии платформы и позволяет копировать строку без запуска 1С.
Конфигурация и версия хранятся отдельно от `ibases.v8i`, участвуют в поиске
и показываются в карточке базы и метке дерева.

История изменений формируется из корневого `CHANGELOG.md`, поэтому сайт и GitHub Release используют один источник данных.

[Посмотреть историю изменений](changelog.md){ .md-button }

## Требования

- Windows 10 или Windows 11, x64;
- установленная 1С:Предприятие 8.3 или 8.5;
- права администратора для обычной работы не требуются;
- подключение к интернету для основной работы не требуется.

!!! info "Независимый проект"
    IBStart распространяется по лицензии MIT и не является официальным продуктом фирмы «1С».
