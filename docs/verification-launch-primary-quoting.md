# Кавычки одиночных основных аргументов конструктора

Дата: 2026-10-21. Версия: 0.8.0. Исправление замечания P1 в PR #16.

## Воспроизведение

При вводе `C:\work files\dump.cf` в поле основного аргумента `/DumpCfg`
редактор вставлял `/DumpCfg C:\work files\dump.cf`. Разбор получал два
позиционных значения вместо одного пути, а проверка минимального числа
аргументов считала строку допустимой. Новые регрессионные проверки сначала
воспроизвели эту проблему в общем обработчике одиночных основных аргументов.

Она распространялась на 40 редакторов в 716 сочетаниях команды и профиля,
включая пути файлов и каталогов, имена и другие одиночные значения.
Это проверка корректного представления одного Windows-аргумента;
она не означает допустимость произвольной строки для порта, даты или email.

## Изменение

Количество основных значений определяется из синтаксиса точного профиля.
Один аргумент автоматически экранируется общим Windows-построителем;
явно заключённое в кавычки значение сначала разбирается один раз, чтобы
не удваивать кавычки. Пробелы вне явно заключённого в кавычки аргумента
допускаются. Пустое поле сохраняет прежнее поведение незаполненного аргумента.

Для двух основных значений сохраняется явный ввод отдельных аргументов,
каждый из которых может иметь свои кавычки. Режим `/debug` остаётся выбором
из перечисления. Открытие конструктора и ручная итоговая строка не выполняют
автоматическое исправление исходного текста. При изменении поля сохраняются
соседние команды, опции, неизвестные фрагменты и их пробелы.

Описание поля в интерфейсе и руководство поясняют автоматические кавычки
для одного значения и отдельные кавычки для нескольких значений.

## Область проверки

| Редакторы | Проверка |
| --- | --- |
| 40 одиночных основных значений, 716 сочетаний с профилями | Пробелы, Unicode, UNC, конечный обратный слеш, встроенные кавычки, уже заключённый в кавычки ввод, повторное редактирование, сохранение соседнего текста |
| `/DumpCfg` | После построения полной команды путь остаётся одним аргументом |
| Два основных значения внешней обработки/отчёта | `/DumpExternalDataProcessorOrReportToFiles` и `/LoadExternalDataProcessorOrReportFromFiles` во всех доступных профилях сохраняют два значения |
| `/debug` | Существующие проверки транспортов и `-attach` продолжают проходить |
| 21 обычный редактор команды | Значение с пробелами, встроенной кавычкой и конечным обратным слешем передаётся одним аргументом |
| 2222 сочетания именованного вложенного параметра и профиля | Кодирование и чтение возвращают исходное значение без потерь; аналогичного дефекта не обнаружено |
| Настоящее окно конструктора | Вставка и повторное применение путей у 9 команд, включая исторический профиль `/SignCfg`; сохранение двух значений у обеих команд внешних обработок |

## Результаты

- Release MSVC C++20, `/W4 /WX`: PASS.
- Итоговый CTest: 8/8 PASS, 42,83 с; в ядре 101 именованный сценарий.
- Python: 44/44 PASS; справочные данные и матрицы воспроизводятся.
- Строгая сборка MkDocs и проверка локальных ссылок, якорей и ресурсов: PASS.
- Снимок настоящего окна `/DumpCfg` просмотрен: значение и итоговая строка
  содержат один заключённый в кавычки путь, описание объясняет автоматические
  кавычки. Регистрация компонентов и процессы 1С не запускались.

Первоначально тест `/SignCfg` проверял одиночный аргумент в современном
профиле, где он уже заменён именованной опцией. Сценарий исправлен:
проверяется исторический профиль 8.3.15; современные именованные опции
охвачены общим обходом. Это уточнение тестового сценария, а не изменение
грамматики 1С.

В одном промежуточном прогоне ядра повторился ранее зафиксированный отказ
Windows при атомарной замене тестового `ibases.v8i`. Проверки кавычек в нём
прошли. Правка не изменяет файловое хранилище; причина отказа не установлена.

Проверки не запускают команды 1С и не используют рабочие базы. Числа относятся
к текущему каталогу и профилям 8.3.6–8.3.27, 8.5.1 и тестовой 8.5.4.
Снимок настоящего редактора `/DumpCfg` сохраняется в
`out/primary-quoting-captures/primary-path-quoted.bmp`.
Журналы: `out/primary-quoting-regression-before.log`,
`out/primary-quoting-ctest.log` и `out/primary-quoting-ui.log`.
