# Обновление справочников 1С

Справочники IBStart описывают совместимость с официальной документацией
1С:Предприятия. Ссылки на приложения 3 и 7 для проверенных версий приведены
в [реестре источников](1c-reference-versions.md).

## Какие данные обновляются

| Документ или данные | Содержание |
| --- | --- |
| [Описание формата](ibases-format.md) | Собственные пояснения полей и статусы реализации |
| [Матрица полей](ibases-format-versions.md) | Идентификаторы и варианты значений по версиям |
| [Реестр версий](1c-reference-versions.md) | Официальные ссылки и различия определений |
| [Параметры запуска](launch-parameters.md) | Собственные требования к совместимости |
| [Матрица конструктора](launch-parameter-versions.md) | Команды и значения поддержанных профилей |

## Проверка новой версии

1. Открыть официальную документацию нужной версии по ссылке в реестре.
   Проверить статус версии и правила обозначений в начале приложения.
2. Сопоставить определения: назначение, синтаксис, обязательность,
   зависимости, значения по умолчанию, ограничения клиента и ОС.
   Учитывать пояснения после заголовка, а не только квадратные скобки.
3. Обновить собственные описания и идентификаторы. Не переносить смысл
   новой версии в старый профиль по одному совпадению имени команды.
   Различать ошибку, условие игнорирования и ограничение редактора.
4. Для новых вариантов изменить каталог, грамматику, редактор и обработку
   секретов. Зафиксировать спорные решения в протоколе проверки.
5. Выполнить проверки ядра и формы. Для утверждения о работе платформы
   отдельно проверить точную установленную сборку 1С.

## Собственные данные программы

Общие пояснения находятся в `src/core/launcher/parameter_help.inc`,
контекстные сведения — в `parameter_context_help.inc`, грамматика — в
`parameter_grammar.inc`, профили — в `parameter_versions.inc`. Эти данные
компилируются в EXE. Официальная документация открывается по ссылке ИТС.

При расширении числа профилей следует проверить ограничения битовых масок
и `cmake/check-launch-parameter-docs.cmake`. Неизвестная версия не получает
варианты соседнего профиля.

## Проверки

```powershell
python tools/update-1c-reference.py --check
python tools/update-launch-parameter-versions.py --check-docs
python -m unittest discover -s tools/tests -p "test_*.py"
cmake --build --preset msvc-x64-release
ctest --preset msvc-x64-release --output-on-failure
git diff --check
```

Генерируемые страницы восстанавливаются из данных проекта:

```powershell
python tools/update-1c-reference.py --docs-only
python tools/update-launch-parameter-versions.py --docs-only
```

Автоматические проверки подтверждают согласованность данных и работу
редактора. Точность пояснений требует сопоставления с официальным источником.
Результаты последней смысловой ревизии описаны в
[протоколе](verification-launch-semantic-audit.md).

Для сайта используется `mkdocs build --strict` с временной копией
`CHANGELOG.md` в `docs/changelog.md`.
