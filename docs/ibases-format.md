# Формат и совместимость `ibases.v8i`

Статус: основной документ по структуре файла и полям.

Дата сверки реестра полей с официальной документацией: 2026-10-19.
Статусы реализации ниже описывают IBStart отдельно от наличия поля в документации 1С.

## Назначение

Документ описывает независимую реализацию чтения, отображения и сохранения
списка информационных баз. Он фиксирует требования к совместимости, а не
копирует страницу документации 1С.

Параметры, которые превращают значения полей в командную строку, описаны в
[документе параметров запуска](launch-parameters.md). Связь двух моделей,
приоритеты и план разработки находятся в
[интеграционной спецификации](ibases-launch-spec.md).

В этот документ включены собственные требования к совместимости, имена полей,
краткие пересказы и ссылки, но не исходные страницы, HTML, CSS, изображения
или фрагменты исходного кода платформы.

## 1. Физический контракт

Редактор `ibases.v8i` должен:

- принимать UTF-8 с BOM и без BOM;
- распознавать секции вида `[Имя секции]`;
- распознавать поля вида `Ключ=Значение`, включая пустое значение;
- сохранять порядок секций и строк;
- сохранять комментарии, пустые строки и строки без `=`;
- сохранять неизвестные ключи при изменении известных;
- не изменять файл при чтении;
- перед записью проверять внешнее изменение файла;
- создавать резервную копию и использовать атомарную замену;
- выдавать диагностику вместо молчаливого исправления неоднозначного файла.

Проверка fingerprint и именованный mutex защищают сохранение от взаимной
перезаписи экземплярами IBStart, использующими этот протокол. Произвольный
внешний редактор может не участвовать в mutex, а Windows не предоставляет
атомарную операцию «сравнить fingerprint и затем заменить файл»; поэтому
короткое окно перед commit остаётся ограничением: после работы другого
инструмента список следует перечитать перед сохранением.

Lossless-слой должен хранить исходное представление. Нормализованное typed-
представление используется для каталога и запуска, но не должно автоматически
переписывать исходный текст.

## 2. Секции

| Тип | Признак | Требование |
| --- | --- | --- |
| База | В секции присутствует `Connect` | Отобразить в каталоге и разрешить запуск после проверки подключения. |
| Группа | В секции отсутствует `Connect` | Использовать имя, `Folder` и порядок; остальные поля сохранять. |
| Пустое подключение | `Connect=` | Сохранить запись, но заблокировать запуск и показать диагностику. |
| Повтор имени | Одинаковое имя без учёта регистра | Не выбирать первую запись молча; неоднозначную операцию заблокировать. |
| Пустой `ID` | Ключ отсутствует или записан как `ID=` | Использовать имя базы как стабильный внутренний идентификатор и показать предупреждение. |
| Повтор `ID` | Несколько баз имеют один стабильный идентификатор | Диагностировать неоднозначность и заблокировать изменение метаданных до исправления файла. |

## 3. Реестр полей

Статусы проекта:

- `APPLY` — значение уже участвует в логике IBStart;
- `PARTIAL` — значение распознаётся или частично применяется;
- `PRESERVE` — значение сохраняется без собственной typed-семантики;
- `TARGET` — поле предназначено для будущей typed-поддержки;
- `EXTERNAL` — поле относится к mobile, web-common или внешнему сервису.

| Ключ | Область | Назначение | Статус проекта |
| --- | --- | --- | --- |
| `Connect` | база | Строка подключения. | `PARTIAL` |
| `ID` | база | Идентификатор записи; используется непустое значение, иначе имя базы. | `PARTIAL` |
| `Folder` | база/группа | Родительская группа или путь в дереве. | `APPLY` |
| `OrderInList` | база/группа | Порядок в плоском списке. | `APPLY` |
| `OrderInTree` | база/группа | Порядок в ветви дерева. | `APPLY` |
| `External` | база | Признак внешней записи. | `PRESERVE` |
| `UseProxy` | web | Режим proxy: 0, 1 или 2. | `TARGET` |
| `PSrv` | web | Адрес proxy. | `TARGET` |
| `PPort` | web | Порт proxy. | `TARGET` |
| `PUser` | web | Пользователь proxy. | `TARGET` |
| `PPasswd` | web | Пароль proxy; не расшифровывать и не записывать в логи в открытом виде. | `TARGET` |
| `ClientConnectionSpeed` | thin/web | Скорость соединения `Normal` или `Low`; целевой параметр `/O`. | `PARTIAL` |
| `App` | база | `Auto`, `ThinClient`, `ThickClient`, `WebClient`. | `PARTIAL` |
| `AppArch` | база | `x86`, `x86_64`, `x86_prt`, `x86_64_prt` или пусто; другое непустое значение диагностируется и блокирует запуск, но сохраняется. | `APPLY` |
| `DefaultApp` | база | Тип клиента по умолчанию при автоопределении. | `PARTIAL` |
| `WA` | база | Аутентификация операционной системы. | `PARTIAL` |
| `WSA` | web | Аутентификация операционной системы на web-сервере. | `TARGET` |
| `Version` | база | Требуемая версия платформы. | `APPLY` |
| `DefaultVersion` | база | Последняя фактически выбранная версия при `/AppAutoCheckVersion`; программа запуска может предпочесть её `Version`. | `PARTIAL` |
| `AdditionalParameters` | база | Raw-строка дополнительных аргументов. | `PARTIAL` |
| `WebCommonInfoBaseURL` | общий список | Источник записи из интернет-сервиса. | `TARGET/PRESERVE` |
| `HttpsCA` | web | Источник корневых сертификатов. | `TARGET` |
| `HttpsCert` | web | Источник клиентского сертификата. | `TARGET` |
| `HttpsCAFile` | web | Файл корневых сертификатов. | `TARGET` |
| `HttpsCertFile` | web | Файл сертификата и закрытого ключа. | `TARGET` |
| `HttpsCertSelect` | web | Политика выбора сертификата. | `TARGET` |
| `HttpsNSSPath` | legacy web | Путь к хранилищу NSS; определение найдено только в документации 8.3.6–8.3.7. | `PRESERVE` |
| `HttpsNSSCertName` | legacy web | Имя сертификата NSS; определение найдено только в документации 8.3.6–8.3.7. | `PRESERVE` |
| `StartupErrorHelpURL` | desktop/client | URL справки при ошибке подключения. | `TARGET/PRESERVE` |
| `StartupErrorHelpText` | desktop/client | Текст или форматированная подсказка. | `TARGET/PRESERVE` |
| `ShowInList` | mobile | Признак отображения в основном списке. | `EXTERNAL` |
| `MobilePublicKey` | mobile | MD5-хеш открытого ключа в Base64 для проверки подписи конфигурации; это не сам ключ. | `EXTERNAL/PRESERVE` |
| `WebCommonInfoBases` | legacy mobile | URL сервиса списка баз: отдельное определение в v8i найдено в 8.3.12–8.3.13; с 8.3.14 эту роль описывает `InternetService`. | `EXTERNAL/PRESERVE` |
| `InternetService` | mobile/общий список | URL сервиса списка баз или дистрибутива. | `EXTERNAL` |
| `DisplayAuthDialog` | mobile | Управление диалогом аутентификации. | `EXTERNAL` |
| `DisableUseBiometrics` | mobile | Скрытие настройки биометрии. | `EXTERNAL` |
| `UseBiometrics` | mobile | Начальное состояние биометрии. | `EXTERNAL` |
| `DisableRememberMe` | mobile | Скрытие функции запоминания входа. | `EXTERNAL` |
| `RememberMe` | mobile | Начальное состояние запоминания входа. | `EXTERNAL` |
| `Locale` | connection/extension | Локаль; уже есть в модели проекта. | `PRESERVE` |

`External` и `Locale` сохраняются проектом, но отдельные определения этих полей
в проверенных разделах `*.v8i` не найдены. Упоминание `WebCommonInfoBases` в
описании `WebCommonInfoBaseURL` или в соседнем разделе `1cestart.cfg` не означает,
что оно определено как ключ v8i в этой версии.

### Изменения по версиям

Ниже — результат сравнения версий документации, а не даты появления возможностей
в исполняемых файлах. Все версии и перечисленные значения приведены в
[матрице](ibases-format-versions.md); ссылки на соответствующие страницы —
в [реестре сверки](1c-reference-versions.md).

| Снимки | Существенное отличие для совместимости |
| --- | --- |
| 8.3.8 против 8.3.7 | Больше нет отдельных определений `HttpsNSSPath` и `HttpsNSSCertName`; значения `NSS` у `HttpsCA`/`HttpsCert` ещё перечислены до 8.3.12 включительно. Эти два факта нельзя объединять в одну дату удаления NSS. |
| 8.3.12 | Найдены `AppArch`, `ShowInList`, `MobilePublicKey`, мобильный `WebCommonInfoBases`. |
| 8.3.13 | В перечислениях `HttpsCA`/`HttpsCert` вместо `NSS` появляются `Linux` и `macOS`. |
| 8.3.14 | Отдельное мобильное поле `WebCommonInfoBases` сменяется `InternetService`; старое написание сохраняется при редактировании старого файла. |
| 8.3.16 | Найдены `DisplayAuthDialog`, `DisableUseBiometrics`, `UseBiometrics`, `DisableRememberMe`, `RememberMe`; эти поля относятся к мобильному клиенту. |
| 8.3.21 | Найдены `StartupErrorHelpURL` и `StartupErrorHelpText`. |
| 8.3.24 | `Connect` помечен обязательным вместо необязательного; описание мобильных полей вынесено в отдельную группу. Это не отменяет поддержку групп без `Connect` в IBStart. |
| 8.3.25 | Для `MobilePublicKey` явно указана обязательность для iOS. |
| 8.3.26 → 8.3.27 → 8.5.1 → тестовая 8.5.4 | Набор определений полей не меняется; в 8.5.4 есть текстовые правки существующих определений. |

Важные зависимости, которые не выражаются одной таблицей наличия:

- для web-подключения отсутствие `UseProxy` означает автоматическое определение;
  при `UseProxy=2` нужны `PSrv` и `PPort`;
- `DefaultVersion` описывает последнюю выбранную программой запуска версию при
  `/AppAutoCheckVersion`; это не универсальный запасной вариант для `Version`;
- `HttpsCAFile`/`HttpsCertFile` имеют смысл при соответствующем значении `File`;
  отсутствующий или пустой путь в документации приводит к варианту `None`, поэтому
  IBStart не должен незаметно подставлять такой результат при ошибке настройки;
- `DisableUseBiometrics` делает `UseBiometrics` незначимым, аналогично
  `DisableRememberMe` и `RememberMe`; начальное значение обоих мобильных флажков — `1`.

Текущая политика IBStart отличается от программы запуска 1С: `DefaultVersion`
учитывается при пустом `Version`, как описано в
[конфигурации приложения](configuration.md).
Это ограничение реализации, а не изменение смысла поля в формате 1С.

## 4. Строка `Connect`

| Вариант | Минимальные фрагменты | Правило typed-представления |
| --- | --- | --- |
| Файловый | `File=каталог` | Сформировать `/F` после проверки пути; при ручном добавлении проверить `1Cv8.1CD`. |
| Клиент-серверный | `Srvr=адрес`, `Ref=имя` | Сформировать `/S` по version profile; не путать адрес кластера и имя базы. |
| Web | `WS=http(s)-url` | Сформировать `/WS` для подходящего клиента, сохранив дополнительные фрагменты. |
| Legacy web | Первый фрагмент — прямой HTTP(S)-URL с непустым хостом | Показать нормализованный URL, но сохранить исходную строку до явного изменения. `;` внутри URL допускается только в кавычках: `Connect="https://host/path;part?x=1"`; без кавычек `;` разделяет фрагменты legacy-строки, а неоднозначная запись отклоняется. |
| Неполный/неизвестный | Нет минимального набора | Показать ошибку; использовать `/IBConnection` только по явной политике. |

Парсер обязан поддерживать quoted values, escaped/doubled quotes, `;` внутри
значений, пустые значения, повторяющиеся фрагменты, IPv4, IPv6 и списки
кластеров. Для HTTP(S)-URL дополнительно проверяются схема, authority,
непустой хост, IPv6 в квадратных скобках, числовой порт в диапазоне 0…65535,
отсутствие управляющих символов, пробелов и неоднозначных кавычек. Нельзя
изменять значение простой заменой кавычек.

## 5. Фактическая реализация IBStart

Typed-представление текущего проекта находится в
[`domain::Database`](https://github.com/ant-m13/ibstart/blob/main/src/core/domain/model.hpp), mapping выполняет
[`MakeDatabase`](https://github.com/ant-m13/ibstart/blob/main/src/core/catalog/catalog.cpp), редактор читает и записывает
известные поля через [`DatabaseEditorDataFromEntry`](https://github.com/ant-m13/ibstart/blob/main/src/ui/database_editor_dialog.cpp)
и [`ApplyDatabaseEditorData`](https://github.com/ant-m13/ibstart/blob/main/src/ui/database_editor_dialog.cpp).

Сейчас применяются к каталогу или запуску:

- `Connect`, `Folder`, `OrderInList`, `OrderInTree`;
- `ID` для внутренней идентификации;
- `Version`, `DefaultVersion`, `App`, `DefaultApp`, `AppArch`;
- raw `AdditionalParameters`.

Читаются и сохраняются, но пока не преобразуются в полноценные аргументы:

- `WA`;
- `External`;
- `Locale`;
- `ClientConnectionSpeed`.

Остальные поля не имеют отдельных typed-полей, но сохраняются lossless-слоем
как неизвестные. Полная поддержка должна добавлять typed view, диагностику,
редактор и применение только после проверки version profile.

## 6. Обратная совместимость и тесты

Нельзя удалять неизвестные поля, менять порядок строк без явного действия,
подменять `Connect` из-за нераспознанного фрагмента или считать `DefaultVersion`
доказательством наличия платформы.

Обязательные тесты:

- BOM/no BOM, CRLF/LF/CR и завершающий перевод строки;
- русские имена, пробелы, emoji, пустые значения и quoted semicolon;
- комментарии и непрозрачные строки до, между и после полей;
- duplicate sections/keys и диагностика пустых имён;
- round-trip каждого поля этого реестра;
- file/server/web/legacy URL, IPv4, IPv6 и cluster list;
- внешний файл, параллельное сохранение, backup и атомарная замена.

Изменения между всеми проверенными версиями фиксируются в
[матрице формата](ibases-format-versions.md) и [журнале сверки](1c-reference-versions.md).
Новая версия добавляется по [единому порядку](maintaining-1c-reference.md),
без копирования всего документа для каждой версии.
