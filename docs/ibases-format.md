# Формат и совместимость `ibases.v8i`

Статус: основной документ по структуре файла и полям.

Дата проверки: 2026-08-27.

## Назначение

Документ описывает независимую реализацию чтения, отображения и сохранения
списка информационных баз. Он фиксирует требования к совместимости, а не
копирует страницу документации 1С.

Параметры, которые превращают значения полей в командную строку, описаны в
[документе параметров запуска](launch-parameters.md). Связь двух моделей,
приоритеты и план разработки находятся в
[интеграционной спецификации](ibases-launch-spec.md).

## Источники

- [Приложение 3. Описание и расположение служебных файлов](https://its.1c.ru/db/v8326doc/content/109/hdoc)
- [Приложение 7. Параметры командной строки запуска «1С:Предприятия»](https://its.1c.ru/db/v8326doc/content/113/hdoc)
- [политика лицензирования материалов 1С:ИТС](1c-license-compliance.md)

MHT-снимки 1С используются только вне репозитория как справочный источник.
В этот документ включены собственные требования к совместимости, имена полей,
краткие пересказы и ссылки, но не исходные страницы, HTML, CSS, изображения
или фрагменты исходного кода платформы.

## 1. Физический контракт

Редактор `ibases.v8i` должен:

- принимать UTF-8 с BOM и без BOM;
- распознавать секции вида `[Имя секции]`;
- распознавать поля вида `Ключ=Значение`, включая пустое значение;
- сохранять порядок секций и строк;
- сохранять комментарии, пустые строки и строки без `=`;
- сохранять неизвестные ключи при изменении известных;
- не изменять файл при чтении;
- перед записью проверять внешнее изменение файла;
- создавать резервную копию и использовать атомарную замену;
- выдавать диагностику вместо молчаливого исправления неоднозначного файла.

Проверка fingerprint и именованный mutex защищают сохранение от взаимной
перезаписи экземплярами IBStart, использующими этот протокол. Произвольный
внешний редактор может не участвовать в mutex, а Windows не предоставляет
атомарную операцию «сравнить fingerprint и затем заменить файл»; поэтому
короткое окно перед commit остаётся ограничением: после работы другого
инструмента список следует перечитать перед сохранением.

Lossless-слой должен хранить исходное представление. Нормализованное typed-
представление используется для каталога и запуска, но не должно автоматически
переписывать исходный текст.

## 2. Секции

| Тип | Признак | Требование |
| --- | --- | --- |
| База | В секции присутствует `Connect` | Отобразить в каталоге и разрешить запуск после проверки подключения. |
| Группа | В секции отсутствует `Connect` | Использовать имя, `Folder` и порядок; остальные поля сохранять. |
| Пустое подключение | `Connect=` | Сохранить запись, но заблокировать запуск и показать диагностику. |
| Повтор имени | Одинаковое имя без учёта регистра | Не выбирать первую запись молча; неоднозначную операцию заблокировать. |
| Пустой `ID` | Ключ отсутствует или записан как `ID=` | Использовать имя базы как стабильный внутренний идентификатор и показать предупреждение. |
| Повтор `ID` | Несколько баз имеют один стабильный идентификатор | Диагностировать неоднозначность и заблокировать изменение метаданных до исправления файла. |

## 3. Реестр полей

Статусы проекта:

- `APPLY` — значение уже участвует в логике IBStart;
- `PARTIAL` — значение распознаётся или частично применяется;
- `PRESERVE` — значение сохраняется без собственной typed-семантики;
- `TARGET` — поле предназначено для будущей typed-поддержки;
- `EXTERNAL` — поле относится к mobile, web-common или внешнему сервису.

## 4. Строка `Connect`

| Вариант | Минимальные фрагменты | Правило typed-представления |
| --- | --- | --- |
| Файловый | `File=каталог` | Сформировать `/F` после проверки пути; при ручном добавлении проверить `1Cv8.1CD`. |
| Клиент-серверный | `Srvr=адрес`, `Ref=имя` | Сформировать `/S` по version profile; не путать адрес кластера и имя базы. |
| Web | `WS=http(s)-url` | Сформировать `/WS` для подходящего клиента, сохранив дополнительные фрагменты. |
| Legacy web | Первый фрагмент — прямой HTTP(S)-URL с непустым хостом | Показать нормализованный URL, но сохранить исходную строку до явного изменения. `;` внутри URL допускается только в кавычках: `Connect="https://host/path;part?x=1"`; без кавычек `;` разделяет фрагменты legacy-строки, а неоднозначная запись отклоняется. |
| Неполный/неизвестный | Нет минимального набора | Показать ошибку; использовать `/IBConnection` только по явной политике. |

Парсер обязан поддерживать quoted values, escaped/doubled quotes, `;` внутри
значений, пустые значения, повторяющиеся фрагменты, IPv4, IPv6 и списки
кластеров. Для HTTP(S)-URL дополнительно проверяются схема, authority,
непустой хост, IPv6 в квадратных скобках, числовой порт в диапазоне 0…65535,
отсутствие управляющих символов, пробелов и неоднозначных кавычек. Нельзя
изменять значение простой заменой кавычек.

## 5. Фактическая реализация IBStart

Typed-представление текущего проекта находится в
[`domain::Database`](../src/core/domain/model.hpp), mapping выполняет
[`MakeDatabase`](../src/core/catalog/catalog.cpp), редактор читает и записывает
известные поля через [`DatabaseEditorDataFromEntry`](../src/ui/database_editor_dialog.cpp)
и [`ApplyDatabaseEditorData`](../src/ui/database_editor_dialog.cpp).

Сейчас применяются к каталогу или запуску:

- `Connect`, `Folder`, `OrderInList`, `OrderInTree`;
- `ID` для внутренней идентификации;
- `Version`, `DefaultVersion`, `App`, `DefaultApp`, `AppArch`;
- raw `AdditionalParameters`.

Читаются и сохраняются, но пока не преобразуются в полноценные аргументы:

- `WA`;
- `External`;
- `Locale`;
- `ClientConnectionSpeed`.

Остальные поля не имеют отдельных typed-полей, но сохраняются lossless-слоем
как неизвестные. Полная поддержка должна добавлять typed view, диагностику,
редактор и применение только после проверки version profile.

## 6. Обратная совместимость и тесты

Нельзя удалять неизвестные поля, менять порядок строк без явного действия,
подменять `Connect` из-за нераспознанного фрагмента или считать `DefaultVersion`
доказательством наличия платформы.

Обязательные тесты:

- BOM/no BOM, CRLF/LF/CR и завершающий перевод строки;
- русские имена, пробелы, emoji, пустые значения и quoted semicolon;
- комментарии и непрозрачные строки до, между и после полей;
- duplicate sections/keys и диагностика пустых имён;
- round-trip каждого поля этого реестра;
- file/server/web/legacy URL, IPv4, IPv6 и cluster list;
- внешний файл, параллельное сохранение, backup и атомарная замена.

Различия между версиями 8.3.20, 8.3.26 и 8.5.1 фиксируются в
[интеграционной спецификации](ibases-launch-spec.md), а не отдельным
копированием всего документа для каждой версии.
