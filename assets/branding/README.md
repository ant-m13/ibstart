# Визуальные материалы IBStart

`ibstart-icon.png` — исходный растровый значок приложения с прозрачным фоном. Из него подготовлен многоразмерный Windows-ресурс `src/app/IBStart.ico` для окна, исполняемого файла и создаваемых ярлыков.

Значок и пиктограммы действий созданы специально для IBStart, не воспроизводят официальный логотип 1С и распространяются вместе с проектом по лицензии MIT.
