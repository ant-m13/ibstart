# Политика безопасности

## Поддерживаемые версии

| Версия | Поддерживается |
| --- | --- |
| `0.7.x` | Да |
| `0.6.x` и более ранние | Нет |

## Сообщение об уязвимости

Не создавайте публичный issue и не публикуйте proof of concept, если сообщение раскрывает уязвимость, ключи, пароли, токены, адреса серверов или данные пользователей.

Используйте кнопку **Report a vulnerability** в разделе **Security** репозитория, чтобы отправить приватный отчёт. Если такой кнопки нет, не раскрывайте детали в issue: сначала запросите у сопровождающего конфиденциальный канал через профиль владельца репозитория [@ant-m13](https://github.com/ant-m13).

В отчёте укажите:

- затронутую версию IBStart и Windows;
- краткое описание воздействия;
- безопасные шаги воспроизведения;
- возможный способ исправления, если он известен.

Сообщения рассматриваются конфиденциально. После подтверждения проблемы будет подготовлено исправление, а автору отчёта будет сообщён план раскрытия информации.

## Рекомендации пользователям

Скачивайте IBStart только из официальных GitHub Releases и сверяйте SHA-256 из `checksums.txt`. Пароль в `ibases.v8i` допустим, но виден в файле и интерфейсе; ярлык IBStart сохраняет только идентификатор базы и не передаёт пароль в командной строке. Не считайте файл или буфер обмена защищённым хранилищем.
